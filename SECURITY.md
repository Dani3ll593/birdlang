# Security Policy / Política de seguridad

[English](#english) | [Español](#español)

<a name="english"></a>
## English

**Reporting a vulnerability.** Please do not open a public issue. Use GitHub's
private reporting instead: [Report a vulnerability](https://github.com/Dani3ll593/birdlang/security/advisories/new).
Describe what you found and how to reproduce it. **Never include anything from a
real call** (audio, subtitles, notes, names or numbers).

**What counts.** Anything that could make Birdlang connect to a network, write
call content to disk, expose the window or clipboard beyond what
`SEGURIDAD_EMPRESAS.md` describes, or run code it should not run. Also problems
in the separate updater (`actualizar.ps1`) or in the published packages.

**Supported versions.** Only the latest release receives fixes.

**What to expect.** Birdlang is maintained by volunteers. We aim to acknowledge
a report within 7 days and to publish a fix, with credit if you want it, as soon
as it is verified.

<a name="español"></a>
## Español

**Cómo reportar una vulnerabilidad.** No abras un *issue* público. Usa el reporte
privado de GitHub: [Reportar una vulnerabilidad](https://github.com/Dani3ll593/birdlang/security/advisories/new).
Cuenta qué encontraste y cómo reproducirlo. **Nunca incluyas nada de una llamada
real** (audio, subtítulos, notas, nombres ni números).

**Qué cuenta.** Cualquier cosa que haga que Birdlang se conecte a una red, escriba
contenido de una llamada en el disco, exponga la ventana o el portapapeles más
allá de lo que describe `SEGURIDAD_EMPRESAS.md`, o ejecute código que no debería.
También los problemas del actualizador aparte (`actualizar.ps1`) o de los
paquetes publicados.

**Versiones con soporte.** Solo la última versión publicada recibe arreglos.

**Qué esperar.** Birdlang lo mantienen voluntarios. Intentamos responder en 7
días y publicar el arreglo, con crédito si lo quieres, en cuanto esté verificado.
