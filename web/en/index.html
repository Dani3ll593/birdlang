What it does

Word-by-word subtitles

Listens only to the call browser (Chrome, Edge, or Brave), never your microphone. Three local models on your processor detect voice activity (Silero VAD), identify the language (VoxLingua107), and transcribe live (Moonshine Streaming).

Numbers and phone numbers in digits

Converts spoken number words to digits, amounts, and times (7:30 p.m.) using fixed rules. If a phrase closed mid-phone number, the English model could invent the missing digits; so when it ends in a number, it waits 1.2 s instead of 0.42 s and labels audio phone numbers "verify".

US streets offline

Searching addresses on web maps sends data outside the computer. Birdlang bundles 10,669 streets and 40,979 postal codes (GeoNames) in memory and resolves Spanish-pronounced street names in 1.87 ms on average (46 out of 48 in first place, 47 out of 48 in the top three).

Glossary of nearly 40,000 terms

Medical, legal, financial, and country-tagged regional terms in an indexed in-memory table. Searches take about 3–4 ms on average (3.59 ms measured) without using the internet.

Privacy in three sentences

See the enterprise security sheet and the privacy policy.

No internet connection

Contains no network code, and every package build automatically checks that no binary includes networking functions.

Nothing from the call is saved

Audio, subtitles, notes, and searches stay only in RAM and are erased on "End session", after 15 minutes without activity, or when closing (a copied phone number is cleared from the clipboard after 20 seconds). The Standard package only saves "don't show again" for the volunteer notice, in preferencias.txt; the enterprise package writes nothing.

Does not translate

Contains no language models or chatbots. Windows hides the window from screenshots and screen sharing, except in "Supervision" mode, with an amber border, which turns off after 20 minutes.

Requirements

64-bit Windows 10 (22H2) and Windows 11, with no dedicated graphics card required.

For IT

Standard package (Birdlang-<version>.zip)

For individual interpreters. Includes the separate actualizar.ps1 script, which queries GitHub Releases only when the user clicks "Check for updates".

Enterprise package (Birdlang-Empresas-<version>.zip)

For corporate networks. Leaves out actualizar.ps1 and hides the update button.

1. Check binaries

From the package folder. If the computer has no .NET SDK, use PowerShell 7 (pwsh):

.\verificacion\verificar_sin_red.ps1

2. Check sockets

While the program is running:

$p = (Get-Process Birdlang).Id
Get-NetTCPConnection -OwningProcess $p
Get-NetUDPEndpoint -OwningProcess $p

3. Process Monitor

As administrator, with Sysinternals Process Monitor downloaded into the verificacion folder (not included). Test sessions of 30 and 40 minutes showed 0 network events and 0 file writes (program shutdown not included).

.\verificacion\procmon_sesion.ps1

Recommendations for IT

Turn on BitLocker (encrypts the page file), turn off hibernation (powercfg /h off), and optionally block Birdlang.exe in Windows Firewall: it does not use the network.

Limits

Windows records that the program ran, not what was said. A process with administrator rights could still read the window even when hidden from screen capture.

How to start and how to contribute

Try it in 3 steps

  1. Download Birdlang-<version>.zip and unpack it on your computer.
  2. Open the call or a bilingual video in Chrome, Edge, or Brave.
  3. Open Birdlang.exe and press "Escuchar" (Listen).

This version is not signed yet: if Windows shows "Windows protected your PC", click "More info" and "Run anyway".

Contribute to the glossary

Never submit real call data, patient names, or confidential information (CONTRIBUTING.md). Regionalisms require confirmation by two native speakers of the country and are published under CC BY-SA 4.0 on GitHub Issues.

Share your metrics

Open the form (no account needed) and, before pressing "Fin de sesión" (End session), which clears the metrics, press "📋 Métricas" (Metrics) and paste the summary. It only holds technical performance data: hardware, timings and counts, never what was said. This tells us how Birdlang runs on more computers.

Frequently asked questions

Does Birdlang translate or use language models?
No. It does not translate or summarize. Its only models are three local acoustic components on the processor: Silero VAD, VoxLingua107, and Moonshine Streaming.
What is saved to the hard drive when the call ends?
Nothing from the call: audio, subtitles, notes, and searches stay in RAM and are erased when closing or after 15 minutes without activity. The only thing the Standard package writes is "don't show again" for the volunteer notice (preferencias.txt, next to the program); the enterprise package writes nothing.
Why does it wait 1.2 seconds when a phone number is dictated?
If the phrase closed during the pause between digit groups, the English model could invent the missing digits. So when the text ends in a number, Birdlang waits 1.2 s before closing the phrase.
Is the window visible during screen sharing?
Windows hides it from screenshots and screen sharing by default. "Supervision" mode makes it visible with an amber border and turns itself off after 20 minutes.
Does it certify HIPAA, GLBA, or GDPR compliance on its own?
No. Birdlang supports the interpreter and does not replace their judgment or their agency's and client's policies.
